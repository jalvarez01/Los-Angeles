# Licencias leídas en la página pública de cada fuente (tramo «Permiso»)

Cómo correrlo: `cd exploracion/permiso && npm install --ignore-scripts && node licencias.mjs` (usa Chrome instalado en el equipo). Abre la página pública de cada fuente integrada en Chrome sin interfaz, lee la licencia como la ve una persona (texto, texto alternativo de íconos y shadow DOM de GeoHub) y la compara con la licencia que tomamos de los metadatos en `catalogo/`. `salida.txt` es la salida real del 2026-11-08.
